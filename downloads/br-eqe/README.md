# Br 实验 EQE 对比

只读实验数据快照。11个日期/变量数据组，41条筛选曲线，5组另有all版本。

各条峰位在980-1450nm内取最大EQE对应波长，再计算峰位均值。各组曲线平均与各条峰位平均分开列示。n=1300nm仅作参考，无关联曲线，不参与平均。

JV为11组74条筛选曲线（Dark69条、Light5条），使用原JV/EQE网站解析器，颜色逐器件匹配EQE原图。原始有符号电流密度保留；对数显示|J|，不抽点、不平滑、不对光暗平均。

Origin -3dB更新为v7，仅含7张完整单器件图和2张组内对比图，页面与图片包均不含高频放大图。圆点为平滑曲线上的预测值，并非新增实测数据，网页未重新拟合。LDR复核版图片6张（仅c组）；80dB为OD1-OD5功率跨度，不是已验证LDR。单器件颜色匹配EQE/JV，组内对比图保持原配色。

噪声ISD为此次isd/a和isd/c目录中的11张图。每条曲线保留全部511个正频率有效点，不抽点、平滑、拟合或平均。a组按完整器件编号匹配EQE配色；c组未给完整点位，保留原标签与原色，不擅自认定为同一器件。F1/F2独立展示，N噪声不关联EQE的n参考曲线。
