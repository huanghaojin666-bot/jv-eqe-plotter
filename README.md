# JV · EQE 数据工作台

这是一个本地网页工具，用于读取仪器导出的 `.txt` 记事本文件并绘制 JV、EQE 曲线。

## 使用方法

1. 双击 `启动网站.bat`。
2. 将 `.txt` 文件拖进页面，或选择一个包含测试数据的文件夹。
3. 在左侧按器件、点位和 light / dark 测量状态筛选曲线。
4. 在左侧“图例名称”中，可直接在彩色短线后输入每条曲线的显示名称；网页图例、图片导出和 Origin 工程共用该名称。
5. 可在“识别结果”中直接修改器件、点位、测量状态和原始曲线名称。
6. 使用“导出 TXT”可得到与仪器文件相同的制表符结构，导出的文件可以直接重新导入本网站作图；“导出 Excel（Origin）”会生成包含“Origin作图”“概览”和“原始数据”三个工作表的 `.xlsx` 文件；“导出 Origin 作图包”会把该 Excel 与当前图的筛选、曲线顺序、配色和坐标轴配方一起保存为 ZIP。图片默认导出为约 5400 × 3300 像素的高清 PNG；如需可无限放大的矢量图，也可选择通常由浏览器打开的 SVG 格式。

## Origin Skill 联动

页面提供配套的 `origin-jv-eqe` Skill，用于把当前视图自动还原为可编辑的 Origin 工程：

1. Windows 本地版在完成筛选、命名、配色和纵轴选择后，直接点击“一键生成并打开 Origin”。
2. 网站会自动调用已安装或项目内置 Skill，先验证作图包，再通过 Origin 官方 `originpro` Python 接口创建不覆盖旧文件的 `.opju`，最后交给 Windows 打开。
3. 只有备份、跨电脑交接或使用静态网页版时，才需要点击“导出 Origin ZIP”。此时也可以将 ZIP 交给 Codex，并说“用 Origin 打开这个包”。
4. 如果本机没有 Origin、64 位 CPython 3.12 或可用 Skill，页面会明确显示失败原因，不会假称工程已创建。

作图包是交给 Skill 的 ZIP，不是图片，包内包含 `data.xlsx` 和 `origin-recipe.json`，完全在浏览器本机生成。Skill 运行后会生成包含可编辑图页的 `.opju`；如需直接得到 PNG/SVG，请使用网站旁边的“导出图片”。Excel 保留原始有符号测量值；JV 对数图所需的 `|J|` 只作为 Origin 显示配方记录，不会改写源数据。

## 已支持的数据

- JV 仪器文件：自动读取一个文件中的多组 `Volt. (V)` 与 `J (A/cm^2)` 数据。
- 光暗状态：优先读取 JV 文件中每组数据对应的 `Mode` 行，也会从曲线名称、文件名或文件夹路径识别 `light` / `dark`（支持“光电流”“暗电流”）；两类曲线均使用实线，并通过名称和筛选区分。
- EQE 处理文件：读取 `Lambda(nm)` 与 `EQE (%)`。
- EQE Raw 文件：读取 `Wavelength (nm)` 与 `EQE (%)`；若同时导入处理文件，会优先保留处理文件。
- 器件识别：支持 `O 1-6`、`P 2-6`、`2-3` 等名称，并可利用文件夹名 `O1`、`P1` 辅助识别。
- 论文图样式：白底黑轴、完整单位、科学计数刻度，图例默认放在图内右下角，每项以对应曲线颜色的短线加自定义名称显示。
- 器件样式：同一器件的所有点位使用同一种可自选颜色，点位通过线型与点形继续区分；可任意勾选一个或多个器件共同显示。
- 光暗配色：可开启“同器件光暗同色”，让同一器件的 Light 和 Dark 曲线使用器件颜色；该模式与渐变配色互斥。
- 坐标标注：可点击曲线标注单个数据点，也可输入横坐标后一键标注全部可见曲线；拖动调整位置，双击坐标文字删除该标注。图例或侧栏隐藏的曲线会保持隐藏，标注会随图片一起导出。
- 可回导 TXT：按当前 JV / EQE 视图和筛选结果导出仪器风格的制表符文本，保留修改后的器件名、点位、Light / Dark、曲线名称、测量时间及全部数据点。
- Origin 兼容 Excel：“Origin作图”页将每条曲线排成相邻的 X/Y 两列，完整保留每个电压或波长数据点，可直接拖入 Origin；概览页按曲线汇总器件、点位、状态、范围和来源，原始数据页保留逐点长表并带冻结表头和筛选。
- Origin Skill 作图包：以带 `schemaVersion` 的 JSON 配方记录当前标题、坐标轴、曲线顺序、最终颜色、线宽和渐变信息，并与 Excel 一起交给配套 Skill。
- 高分辨率导出：PNG 使用较大字体和清晰坐标，适合论文、汇报和后续排版。

所有解析和作图均在浏览器本机完成，数据不会上传到网络。

页面右上角使用深圳技术大学官网提供的透明背景 SVG 矢量标识，缩放保持清晰；资源来源记录在 `assets/SOURCES.md`。

## 分享给其他人

本项目可以作为纯静态网站发布。公开网站仍在访问者自己的浏览器中读取和处理 `.txt` 文件，不会把实验数据上传到托管服务器。

推荐使用 GitHub Pages：

1. 在 GitHub 创建一个仓库，并将本项目推送到 `main` 分支。
2. 打开仓库的 `Settings` → `Pages`，将 Source 设为 `GitHub Actions`。
3. 仓库中的 `Deploy website` 工作流会自动发布网站，并在运行结果中显示公开网址。
4. 以后修改本项目并推送到 `main` 分支，公开网站会自动更新。

自动发布只包含网站实际需要的 HTML、JavaScript、样式、图片和 Plotly 文件，不会发布本地启动脚本、测试文件或本地保存服务。
